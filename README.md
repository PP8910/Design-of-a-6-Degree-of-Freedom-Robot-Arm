# Design-of-a-6-Degree-of-Freedom-Robot-Arm
Đề tài tập trung thiết kế và xây dựng robot 6 bậc tự do, bao gồm mô hình toán học, động học thuận – nghịch, điều khiển PID và điều khiển mờ. Hệ thống được mô phỏng trên MATLAB/Simulink và thiết kế cơ khí thực tế. Robot được tích hợp xử lý ảnh với YOLOv8 và webcam để nhận diện, xác định tọa độ và gắp vật tự động với độ chính xác cao.
